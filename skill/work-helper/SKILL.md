# 업무 도우미

Codex와 Claude Code의 로컬 Python 실행 환경에서 사용한다. 이 Skill은 독립 배포본이 아니라 Work-Helper 저장소의 `backend/`를 호출한다. 원본 엑셀을 수정하지 않는다.

## 실행 준비

- Skill 위치를 기준으로 `scripts/work_helper.py`의 절대 경로를 구한다. 현재 작업 디렉터리가 저장소 루트라고 가정하지 않는다.
- Python 3와 `openpyxl`이 필요하다. 미설치 시 사용할 Python 환경에 `python -m pip install -r "<skill-dir>/requirements.txt"`로 설치한다.
- 아래 예시의 `<cli>`는 해당 스크립트의 절대 경로다. 경로와 문자열을 셸에 맞게 인용한다.
- 저장소 안에서 실행하거나 Skill 폴더를 심볼릭 링크로 연결하면 백엔드를 자동으로 찾는다. Skill 폴더만 복사했다면 `python "<cli>" --repo-root "<Work-Helper 저장소 경로>" <명령> ...`을 사용한다. `--repo-root`는 하위 명령 앞에 둔다.
- 명령은 JSON을 stdout으로 반환한다. `ok: false` 또는 종료 코드 1이면 오류를 보고하고 입력을 수정한다. 인자 사용 오류는 종료 코드 2다. 성공 결과에도 `warnings`, `missing`, `skipped`가 있을 수 있으므로 확인한다.

## 엑셀 취합

폴더, 파일명 접두어, 시트명, 헤더 행을 확인한다. 헤더는 **1부터 시작**, `0`은 헤더 없는 데이터다. 시트명과 헤더 행은 쉼표로 구분한다. 헤더 행 하나는 모든 시트에 적용하며, 여러 개면 시트 수와 같아야 한다.

```shell
python "<cli>" merge --folder "<입력 폴더>" --prefix "실적_" --sheets "실적,계획" --headers "1,2"
```

하위 폴더까지 처리하라는 요청에는 `--recursive`를 추가한다. `.xlsx`만 취합하며 `~$` 임시 파일은 제외한다. 접두어는 파일명으로 사용 가능한 문자열이어야 한다. 빈 접두어는 모든 `.xlsx`를 선택하므로 이전 `[취합]` 결과가 입력에 섞이지 않게 확인한다.

실행 시 입력 폴더에 `[취합]<접두어>_<날짜시간>.xlsx`가 저장된다. 값 중심 취합이며 원본 서식·수식·매크로를 보존하는 병합이 아니다. 수식은 Excel이 마지막으로 저장한 계산값을 사용하므로 계산값이 없는 파일은 먼저 Excel에서 계산 후 저장해야 한다. 결과 경로, 행 수, 시트별 제외 파일과 이유를 보고한다. 같은 접두어로 같은 초에 반복 실행하면 결과명이 겹칠 수 있으므로 즉시 중복 실행하지 않는다.

## 주소록 수신·참조 목록

먼저 주소록의 인식된 컬럼과 실제 팀·역할 목록을 확인한다.

```shell
python "<cli>" roster --file "<주소록.xlsx>"
python "<cli>" recipients --file "<주소록.xlsx>" --teams "개발팀,영업팀" --to-roles "팀장" --cc-roles "팀원"
```

- `--teams`는 쉼표로 구분한 팀 또는 상위 조직이다. `전체`는 모든 팀이다. 팀 이름은 부분 일치도 허용하므로 `matched_teams`가 요청한 범위와 맞는지 확인한다.
- 역할도 쉼표로 구분한다. 인식된 역할을 사용하고, 수신·참조 중 적어도 하나의 역할을 지정한다. 같은 이메일이 수신과 참조에 있으면 참조에서 제외된다.
- **기존 선택 규칙:** `팀QA`, `담당`, `담당임원` 또는 이름이 `장`으로 끝나는 역할만 팀·상위 조직 조건으로 제한된다. `팀원` 등 나머지 역할은 지정 팀과 관계없이 주소록 전체에서 선택된다. 일반 역할을 지정할 때 이 범위를 알리고 결과의 실제 팀 목록을 확인한다. 특정 팀의 일반 구성원만 요청한 경우 이 명령만으로 충족했다고 보고하지 않는다.
- 텍스트 저장 요청이 있으면 `--save-txt`를 추가한다. 주소록 폴더에 `메일주소_<날짜시간>.txt`가 생성되고 `out_path`가 반환된다.
- 결과의 `to_join`, `cc_join`을 복사 가능한 형태로 제공하고 미매칭 조직과 경고를 알린다. 실제 메일은 발송하지 않는다.
- 주소록 처리 결과에는 개인정보가 포함된다. 전체 원본이나 불필요한 상세 목록을 대화에 붙이지 않고 요청에 필요한 결과만 제시한다. 로컬 Python 처리와 AI에 결과를 전달하는 것은 구분한다.

## 엑셀로 폴더 생성

시트와 컬럼을 읽고, 실제 헤더 이름을 사용한다. 하위 컬럼을 생략하면 상위 폴더만 만든다.

```shell
python "<cli>" folder-info --file "<폴더목록.xlsx>"
python "<cli>" folders --file "<폴더목록.xlsx>" --sheet "목록" --upper-col "사업부" --lower-col "팀" --number-mode digit
```

기본 실행은 **미리보기만** 반환한다. 생성 위치가 지정된 폴더 생성 요청에는 같은 옵션에 `--create --output-dir "<생성 위치>"`를 추가한다. 필요한 입력이 이미 있으면 재확인을 요구하지 않고 진행한다. 미리보기만 요청한 경우에는 생성하지 않는다.

번호 방식은 `none`(없음), `digit`(`01.`), `alpha`(`A.`)이며 기본값은 `digit`이다. 백엔드는 첫 등장 순서로 중복을 제거하고 Windows 금지 문자를 `_`로 바꾼다. 폴더 컬럼도 저장된 계산값을 읽는다. 생성 결과의 위치, 생성 수, 기존 수를 보고한다. 기존 폴더는 삭제하지 않는다.

## 발견 및 호출

사용자가 이 파일 경로를 지정하면 바로 읽어서 사용할 수 있다. `skill/` 자체는 기본 자동 발견 위치가 아니다. 자동 발견이 필요하면 이 폴더를 다음 위치에 심볼릭 링크로 연결하거나 복사한다. 복사 시 실행에 `--repo-root`가 필요하다.

- Codex: 저장소의 `.agents/skills/work-helper/` 또는 사용자 홈의 `.agents/skills/work-helper/`. `$work-helper`로 호출한다.
- Claude Code: 저장소의 `.claude/skills/work-helper/` 또는 사용자 홈의 `.claude/skills/work-helper/`. `/work-helper`로 호출한다.

설치 위치 참고: [Codex 공식 문서](https://learn.chatgpt.com/docs/build-skills), [Claude Code 공식 문서](https://code.claude.com/docs/en/skills).

검증은 저장소에서 `python "<skill-dir>/scripts/test_work_helper.py"`로 실행한다. 실제 업무 파일 대신 임시 샘플 엑셀을 사용한다.
